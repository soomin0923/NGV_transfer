ImageNet과 직접 학습 모델 — 카메라 비교 분석

이 보고서는 현재 실행에서 읽은 실제 데이터와 측정값으로 생성했습니다. 그림은 HTML 내부에 포함되어 인터넷 없이 열립니다.

이 실습에서 무엇을 비교하나요?

ImageNet으로 미리 학습된 범용 분류기와 직접 촬영한 라벨로 학습한 분류기가 같은 카메라 장면에 어떻게 반응하는지 비교합니다. 모델이 배운 클래스 정의가 서로 다르므로 서로 다른 라벨의 confidence를 곧바로 정확도로 읽지 않습니다.

아래 정확도는 학생이 브라우저에서 기록한 새 프레임에 대한 관찰값입니다. 연속 영상의 프레임은 서로 비슷할 수 있어 독립적인 대규모 테스트를 대신하지 않습니다. 클래스와 조건을 골고루 바꾸고, 촬영 학습에 사용하지 않은 장면을 기록하세요.

1. 라벨·조건별 표본 수

표본이 부족하거나 없는 칸을 먼저 찾으세요. 밝기·거리·배경을 바꾸어 기록하되 각 조건의 의미를 일관되게 사용합니다.

2. ImageNet 의미 정확도는 아직 계산하지 않습니다

--mapping을 제공하지 않았습니다. ImageNet의 원래 예측 라벨과 confidence는 볼 수 있지만, 수업 라벨과의 의미 대응 정확도는 비워 둡니다. mapping JSON을 직접 검토한 뒤 다시 실행하면 같은 기록에서 대응 점수를 계산합니다.

4. 집계 표

정확도와 포함률은 0~1 비율입니다. observed_median_ms가 있다면 브라우저에서 기록한 단일 추론 시간들의 중앙값이며, 워밍업·반복 측정으로 구성한 정식 벤치마크와 구분합니다. 비어 있는 값은 측정 또는 대응 정보가 없다는 뜻입니다.

실습에서 답할 질문

  1. 범용 ImageNet 분류기가 알고 있는 사물과 직접 정한 라벨이 어떻게 다른가요?
  2. 동일한 물체라도 배경·거리·방향이 바뀌면 두 모델의 예측은 어떻게 달라지나요?
  3. confidence가 높지만 틀린 프레임이 있나요? 그 점수를 실제 정답 확률로 읽어도 될까요?
  4. 라벨 대응을 명시했을 때 같은 프레임에서 어떤 모델이 더 자주 맞추나요? 표본 수는 충분한가요?
  5. ImageNet Top-5에 정답 의미가 포함되더라도 Top-1은 틀릴 수 있나요?
