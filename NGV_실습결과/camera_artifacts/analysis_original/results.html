카메라 분류: 측정 결과 분석

직접 촬영한 세션을 학습·검증·테스트로 분리하고, 같은 학습 모델의 FP32 / dynamic / full INT8 배포 결과를 비교합니다. 아래 값은 실행 결과에서 읽은 실제 측정값입니다.

1. 같은 테스트 데이터에서 정밀도 비교

정확도 = 전체 정답 비율, macro-F1 = 클래스별 F1의 단순 평균입니다. F1은 precision(해당 라벨로 예측한 것 중 정답 비율)과 recall(실제 해당 라벨 중 찾아낸 비율)을 함께 봅니다. 모델 크기는 파일 바이트 수입니다.

시간은 warm-up 후 각 테스트 이미지를 한 번씩 추론해 측정했습니다. 이미지 읽기·크기 조정·카메라·웹 표시 시간은 제외하고, INT8 입력 양자화와 출력 역양자화는 포함합니다. P95는 측정값의 95백분위입니다. 같은 CPU·스레드·데이터로 비교하며, 작은 표본이나 백그라운드 작업은 시간에 영향을 줍니다. 양자화가 모든 CPU에서 더 빠른 것은 아닙니다. execution_path가 builtin_cpu_no_default_delegates라면 XNNPACK이 해당 INT8 그래프를 처리하지 못해 같은 INT8 모델을 기본 CPU 정수 커널로 실행한 것입니다. FP32 모델로 바꾼 것이 아닙니다.

2. 학습 곡선

실선은 학습, 점선은 검증입니다. 학습 정확도만 오르고 검증 정확도가 떨어지면 과적합을 의심합니다. head는 분류층 학습, fine_tuned는 일부 backbone 추가 학습입니다. 최종 모델은 validation으로 선택하며 test 점수로 다시 고르지 않습니다. 선택 모델: best_head.
