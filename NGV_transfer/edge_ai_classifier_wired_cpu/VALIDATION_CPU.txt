한계:
- 실제 Raspberry Pi ARM64/교실 USB 카메라/Windows PowerShell/SSH는
  이 환경에서 실행하지 못함. Pi용 CLI 실행 검증은 x86 CPU에서 수행.
- 카메라 기록은 모의 입력 검사이며 실제 촬영 성능이 아님.
- 전체 기본 epoch 학습의 정확도·시간은 측정하지 않음.
  축소 실행은 실행 경로 검증이며 강의에서 기대할 정확도 예시가 아님.
- INT8·dynamic·가지치기가 항상 빠르거나 정확도를 유지하지는 않음.
  실제 평가·모델 해시·장치·스레드·배치별 결과로 판단.
- 각 Ubuntu의 기본 apt 라이브러리는 수업 전에 해당 OS 저장소에서 설치.
  각자 다운로드하는 WSL 패키지는 명시한 ABI 범위로 제한하며 모든 Ubuntu
  실장비를 시험한 것은 아님. Pi는 본인 OS의 Python/OpenCV를 설치하고
  호환되는64비트 Python3.11~3.13용 LiteRT 패키지를 직접 다운로드함.
